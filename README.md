# Little Lemon Capstone SwiftUI Project

A complete SwiftUI sample for the iOS Developer Capstone peer-review assignment.

## Included

- 3-page onboarding flow
- Saved profile data using `@AppStorage`
- Home screen with header, hero, search, category filters, and menu list
- Profile screen with editable data and logout
- Stack navigation with back button

## How to run

1. Open `LittleLemonCapstone.xcodeproj` in Xcode.
2. Select an iPhone simulator.
3. Press Run.
